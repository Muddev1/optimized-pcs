# Optimized PCs

We sell PC parts and build customs for you. This is the source for the Optimized PCs website — a clean, static HTML/CSS/JS site with a shop-style product grid, a working shopping cart, and a custom-build request flow.

## Live site

https://muddev1.github.io/optimized-pcs/

## Local development

No build step — just open `index.html` in a browser, or serve the folder with any static file server.
